# Secret Santa Telegram Bot

Простой Telegram-бот для нескольких независимых игр в Тайного Санту.

Бот: [@secret_2g_santa_bot](https://t.me/secret_2g_santa_bot)

## Что умеет

- создавать сколько угодно игр с уникальным шестизначным кодом и ссылкой;
- регистрировать имя, пожелание и необязательную фотографию;
- не допускать повторов имён с учётом регистра, пробелов и `ё/е`;
- показывать список зарегистрированных и позволять выйти до старта;
- задавать взаимные исключения (например, для пар);
- проводить криптографически случайную дерранжировку без самовыбора и повторов;
- навсегда сохранять результат — повторный запрос показывает того же человека;
- отправлять результат только дарителю, не раскрывая пары даже организатору;
- использовать современные цветные кнопки Telegram и кнопку копирования кода;
- подхватывать смешные картинки из `assets/` без изменения кода.

Создатель комнаты управляет игрой, но не включается в список автоматически. Если он
хочет участвовать, достаточно нажать «Присоединиться к игре» как всем остальным.

## Быстрый запуск

Нужен Python 3.11+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `BOT_TOKEN` в `.env`, затем:

```powershell
python -m app
```

Или через Docker:

```powershell
docker compose up -d --build
```

База SQLite сохраняется в Docker volume `santa_data`.

## Картинки друзей

Положите готовые изображения в [`assets/`](assets/README.md). Примеры имён:

```text
welcome_vika.jpg
created_archyz.png
joined_neman.webp
drawn_all_friends.jpg
```

Файлов с одним префиксом может быть сколько угодно — бот выбирает случайный. Фото,
загруженное человеком при регистрации, Telegram хранит сам; бот сохраняет только
непубличный `file_id` и отправляет фото исключительно назначенному дарителю.

## Развёртывание 24/7 на Railway

Проект уже содержит `Dockerfile` и `railway.toml`.

1. Создайте проект из этого GitHub-репозитория в Railway.
2. Добавьте переменные `BOT_TOKEN`, `BOT_USERNAME=secret_2g_santa_bot`,
   `DATABASE_PATH=/app/data/secret_santa.db`, `ASSETS_DIR=/app/assets`.
3. Добавьте постоянный Volume и смонтируйте его в `/app/data`.
4. Запустите Deploy. Веб-домен не требуется: бот работает через long polling.

Без Volume SQLite исчезнет при пересборке контейнера. Для большого публичного бота
стоит перейти на PostgreSQL, но для небольшой компании SQLite с WAL проще и надёжнее.

## Проверка

```powershell
pip install -r requirements-dev.txt
pytest -q
```

Тесты проверяют отсутствие самовыбора и повторов, соблюдение исключений, невозможные
наборы ограничений и нормализацию имён.

## Безопасность

- `.env`, база и локальные данные исключены из Git;
- организатор не получает таблицу соответствий;
- жеребьёвка и смена статуса выполняются одной транзакцией;
- бот работает только в личных чатах по фактическому Telegram ID пользователя.

Если токен когда-либо отправлялся в чат или публиковался, перевыпустите его через
`@BotFather` командой `/revoke` и замените `BOT_TOKEN` на сервере.
