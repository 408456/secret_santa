# Картинки бота

Просто положите сюда `.jpg`, `.png` или `.webp`. Код менять не нужно.
Бот случайно выбирает файл по префиксу события:

- `welcome_` — главное меню (`welcome_ded_moroz.jpg`)
- `created_` — игра создана (`created_archyz.png`)
- `joined_` — участник зарегистрировался (`joined_neman.webp`)
- `drawn_` — жеребьёвка завершена (`drawn_group.jpg`)

Можно положить несколько картинок с одинаковым префиксом — при каждом сообщении будет
выбираться случайная. Личная фотография участника загружается прямо в Telegram при
регистрации и не хранится файлом на сервере.
